# 웹소켓 활용 시나리오

`eureka-sockets-api`는 마이크로서비스 환경에서 이벤트 기반 실시간 통신을 제공하는 웹소켓 서비스입니다.

_외부 서비스에서 발생하는 이벤트를 SQS/SNS를 통해 수신하고, 채널 기반으로 클라이언트에게 실시간 메시지를 전달합니다._

## 아키텍처

[마이크로 서비스] → [SQS/SNS] → [소켓 서비스] → [채널 라우팅] → [웹소켓 클라이언트]

### 메시지 플로우

1. 외부 마이크로서비스에서 비즈니스 이벤트 발생
2. SQS 또는 SNS로 이벤트 메시지 발송
3. 소켓 서비스에서 메시지 수신 및 처리
4. 채널별로 구독 중인 클라이언트들에게 메시지 브로드캐스트
5. 클라이언트에서 실시간 메시지 수신 및 후속 처리

## 채널 구조

채널명은 `{service}:{modelType}` 형식을 사용합니다.

- **service**: ??
- **modelType**: ??

**예시**:

- `lemon-orders-api:order` - 주문 관련 이벤트
- `lemon-payment-api:payment` - 결제 관련 이벤트
- `eureka-backend-api:user` - 유저 관련 이벤트

## 활용 시나리오

### 주문 상태 실시간 알림

**시나리오**: 주문 생성, 상태 변경, 취소 등의 이벤트를 실시간으로 사용자에게 전달

**플로우**:

1. **이벤트 발생**: 주문 서비스에서 주문 생성/변경 이벤트 발생
2. **메시지 발송**: 주문 서비스가 SQS/SNS로 이벤트 메시지 전송
3. **이벤트 수신**: 소켓 서비스에서 SQS/SNS 메시지 수신
4. **채널 라우팅**: 주문 채널로 메시지 라우팅
5. **메시지 브로드캐스트**: 해당 채널을 구독한 클라이언트들에게 메시지 전송
6. **클라이언트 처리**: 클라이언트에서 메시지 수신 후 주문 ID로 최신 정보 조회

**메시지 예시**:

```json
{
  "channel": "lemon-orders-api:order",
  "event": "status_changed",
  "data": {
    "id": "ORD-2025-001",
    "type": "order",
    "sid": "12345",
    "uid": "23456",
    "ts": "2025-12-10T10:30:00Z"
  }
}
```
